# COURTSIDE · 3D Tennis

基于 Three.js 与 cannon-es 的卡通网球游戏。

**在线游玩：https://y523742204.github.io/tennis-game/**

## 运行

需要 Node.js 22 或更新版本，不需要安装 npm 依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173/ 。请通过 HTTP 服务访问，浏览器直接打开 HTML 文件可能拦截 ES Module。

## 操作

- 开始菜单设置每盘 2、4、6 局、对手难度，以及占先制或金球制。
- 指向对方半场选择目标，长按球场展开击球操作。
- 发球：拖动圆盘中心选择平击、上旋、侧旋，支持混合旋转。
- 回球：对手出球后即可长按预选。向上、左下、右下拖动选择上旋、平击、切削。
- 松手锁定力量、球路和目标，到达预判的腰部击球点后自动执行；仍按住时按当前选择出手。未操作默认平击。
- 右侧力量条的中央金色区域触发 Perfect：球速加成，击球体力消耗减少。
- 自动接球、击球后回位；跑动与击球消耗体力，回合中每秒恢复 2 点。
- 每分结束补满至当前上限；本分首次耗尽体力后，下分上限乘以 90%（100→90→81），每局结束恢复至 100。双方独立计算，一发失误和擦网重发不结算体力。
- 体力越低移动越慢；低于 30 点时球速和稳定性逐渐下降，零体力时球速系数为 70%，落点最大随机偏移 1.6 米（可能出界）。Perfect 仍有加成，但不能免除疲劳影响。
- `P` 暂停或继续；`Esc` 打开比赛设置；点击球场或空格进入下一分。

## 手机与平板

- 支持竖屏、横屏和刘海安全区；球场取景会随屏幕比例重新计算。
- 触摸对方半场选择目标，保持按住展开圆盘或击球气泡。短距离向上、向左、向右拖动即可选择回球方式。
- 右上角 `⋯` 打开暂停与比赛设置，无需键盘。
- 旋转屏幕或切到后台时会暂停比赛，回到游戏后轻触球场继续。
- 手机端使用较低的渲染分辨率和阴影精度，选球预览按较低频率刷新；球的物理模拟与比赛规则保持一致。

计分包括 15/30/40、占先、金球、局末换发、发球区轮换、双误、擦网重发及抢七。当前为单盘比赛。

## 验证与部署

```sh
npm test
```

主分支更新后，GitHub Actions 运行测试并将 `dist/` 部署到 GitHub Pages。所有网站资源使用相对路径，支持 `/tennis-game/` 项目路径。

## 项目结构

- `dist/`：可直接部署的静态网站。
- `dist/player.js`：卡通球员和关节动画。
- `dist/flight.js`：旋转与空气作用力。
- `dist/tactics.js`：弹跳后击球点与回位。
- `dist/return-strategy.js`：来球预选、锁定及到点执行。
- `dist/viewport.js`：手机取景、安全区、圆盘位置与拖动方向。
- `dist/rules.js`：网球计分与发球顺序。
- `tests/`：物理、策略与规则测试。
- `serve.cjs`：本地静态服务。

第三方依赖固定为 Three.js 0.170.0 与 cannon-es 0.20.0，随网站一同提供，无需 CDN。许可证位于 `dist/vendor/`。
